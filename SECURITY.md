# Security Policy

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/TRUGS-LLC/TRUGS-AGENT/security/advisories/new).

The 2.0.0 installer is an unreleased candidate. It places only the files it lists
inside the chosen project, requires terminal consent to replace existing files,
and refuses symlink destinations. Its self-check validates instruction syntax and
vocabulary, not the behaviour of an agent reading the instructions.

The older Python index releases receive no updates. Never include credentials or
personal information in an example or public report.
