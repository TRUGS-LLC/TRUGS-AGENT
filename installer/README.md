# trugs-agent

The installer of the TRUGS onboarding kit. In a project, `trugs-agent install`
lists AGENTS.md, CLAUDE.md, the Cursor rule and the plugin manifest before
writing them; existing files require a terminal and an explicit `yes`. Then
`trugs-agent check` validates the placed files.

Install it with `pip install trugs-agent`. The kit's instructions, primer,
lessons and repository map are at https://github.com/TRUGS-LLC/TRUGS-AGENT,
under the Apache License 2.0.
