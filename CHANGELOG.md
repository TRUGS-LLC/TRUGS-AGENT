# Changelog

## 2.0.0

Rebuilt as an onboarding kit: one instruction source and generated forms, a primer,
runnable examples, six task skills, the repository map, a consent-based installer,
and an offline check. Apache-2.0.

## 2026-10-16

Kept the official Apache License text and attribution while preparing this rebuild.

## Earlier releases

Versions 1.0.0 and 1.1.0 were published on the Python package index. Version 1.2.0
was a repository release only. Earlier files and release notes remain in public git
history. Version 2.0.0 replaces the earlier index installer with this onboarding kit.
