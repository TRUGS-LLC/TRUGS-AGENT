# TRUGS-AGENT

Under reconstruction. This repository is being rebuilt as the place to send an AI agent so that it understands TRUGS. Until then, start with the TRUGS specification (https://github.com/TRUGS-LLC/TRUGS) and the trug command (https://github.com/TRUGS-LLC/TRUGS-TOOLS).

## Scope

This software does not include self-modifying TRUGS: graphs that change their
own structure while they run.
